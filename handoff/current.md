# 当前接力记录

- 阶段：15，已知训练帧与 QPSK 数据帧交替进入 FPGA 的 IFFT → CP → FFT 板内回环。
- 数据帧采用 52 个有效子载波，其中 4 个固定导频、48 个 Gray QPSK 数据子载波；固定 LFSR 种子为 `16'hACE1`，每个数据帧产生 96 bit。
- PL 检查器比较训练/导频幅值、保护带、帧尾和 QPSK 硬判决，累积帧数、总比特数和误码数。LED0 心跳、LED1 数据帧通过、LED2 收到完整帧、LED3 历史错误。
- 验证：XSim 连续 4 个数据帧共 384 bit，误码 0；另注入一次 I 符号翻转，独立检查器准确记录 1 bit 错误。Python 测试 11 项通过。Vivado 2024.1 已完成综合、布局布线和 bitstream，DRC 0 错误，布线后 WNS +0.710 ns；2026-09-23 经 JTAG 下载到 xc7z020，启动状态 HIGH。板上 LED 的实际亮灭仍需肉眼确认。
- 当前限制：无数字回波信道、噪声、同步、均衡、PS/DMA 和结构感知；硬件计数器尚无板外读出；20 MHz 连续无丢样未验证。JTAG 下载断电不保存。
- 下一步：增加带真值的数字距离/载波相位信道，在接收端加入训练符号信道估计；之后做有噪声 BER 曲线与距离门。
