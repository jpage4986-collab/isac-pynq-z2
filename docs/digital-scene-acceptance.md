# 可变数字目标、微振动与噪声验收

`model/digital_scene.py` 是下一阶段 FPGA 目标信道和感知处理的浮点真值。每个 100 Hz 慢时间采样对应一个已知 OFDM 训练符号；同一时刻的 QPSK 数据符号通过同一组目标响应。目标由整数延迟格、复反射幅度、静态相位和正弦位移定义。多个目标的频域响应相加，训练符号测得 `H=Y/X`，保护带与直流频点置零后做 64 点距离 IFFT。通信支路用训练符号估计的信道和数据符号导频恢复 QPSK。

这仍是**板内数字信道的 PC 黄金模型**。它不证明真实 5.8 GHz 无线链路、桥梁现场振动或 PYNQ-Z2 端的动态目标已完成。`carrier_hz=5.8e9` 只进入 `-4πR/λ` 的数字相位公式。

在 Windows PowerShell 中运行：

```powershell
cd D:\pynqz2\isac-pynq-z2
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe scripts\report_digital_scene.py
```

脚本写出 `reports/digital_scene_20260923.json`，使用固定随机种子，后续三人接力可逐字段比较。正式慢时间窗口为 4096 点、100 Hz（40.96 秒），数字目标位于第 5 距离格，振幅 500 μm，感知复数高斯噪声为 30 dB。按目标门复数序列的相邻共轭乘积累计相位，再换算相对位移；主频使用去均值 Hann 窗和非直流 FFT 峰值。

| 输入频率 | 估计频率 | 相对位移 RMSE | 第 5 格峰值正确率 |
| --- | ---: | ---: | ---: |
| 2.40 Hz | 2.392578 Hz | 20.30 μm | 4096/4096 |
| 2.05 Hz | 2.050781 Hz | 16.78 μm | 4096/4096 |

两种频率误差均低于 0.05 Hz，位移 RMSE 均低于 50 μm；这些是以上**指定输入和噪声条件**下的仿真结果。多目标测试另包含第 5 格活动目标和第 10 格较弱活动目标，验证了目标响应叠加、目标门和通信均衡，不能由此推论任意间距/幅度目标都可分辨。

BER 扫描使用同一个第 5 格微振动目标，1024 个数据帧，每帧 96 bit，总计 98,304 bit；每个信噪比点使用相同随机种子生成数据和噪声，便于复现：

| SNR | 比特错误数 | 实测 BER |
| ---: | ---: | ---: |
| 0 dB | 34289 | 0.348806 |
| 5 dB | 13440 | 0.136719 |
| 10 dB | 1615 | 0.016429 |
| 15 dB | 4 | 0.00004069 |
| 20 dB | 0 | 0/98304 |
| 30 dB | 0 | 0/98304 |

最后两行表示有限样本中未观察到错误，不表示真实 BER 必然为零。FPGA 动态目标和位移/频谱链必须以这些输入条件、相位符号和误差定义做对照。
