# 模型与接口约定（v0.1）

- IQ接口：I为低16位，Q为高16位；二补码；内部小数位由模块格式表指定。
- OFDM：64点、CP16、QPSK；先做全子载波数字闭环，不声称符合某个无线标准。
- 距离：20 MHz带宽理论距离单元约7.5 m；37.5 m起点使用5个整数采样延迟。
- 载波：5.8 GHz只用于数字相位，波长为 `c/fc`。
- 位移方向：远离雷达为正；回波相位为 `-4*pi*delta_R/lambda`；恢复位移保留负号。
- 感知：`H=Y/X`；目标门复数序列使用 `q[m]=z[m]*conj(z[m-1])`。
- 慢时间：100 Hz；1024窗用于快速观察，4096窗用于正式主频验收。
- 训练：通信均衡只能使用训练符号或导频，不得使用未知载荷真值。
