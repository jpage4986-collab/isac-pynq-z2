# 实施路线

## 0. 环境冒烟
三人能运行 Python 测试；Vivado 能创建 Zynq-7000 小工程；PYNQ-Z2 能启动并访问 Jupyter；自建 AXI-Lite 寄存器模块能读写。

## 1. DMA 环回
完成 AXI DMA simple mode 环回，测试长度 1、16、64、1024；确认 TLAST、字节长度、连续内存和超时恢复。

## 2. OFDM 通信
64 点 QPSK IFFT/FFT、CP16、训练符号、均衡和 BER。无噪声多种子 BER=0 后再做噪声扫描。

## 3. 单目标数字感知
整数延迟 5 点作为约37.5 m示例，H=Y/X、距离 IFFT、目标门、共轭乘积、相位和位移。

当前进度：已完成独立的 5 点 AXI-Stream 数字延迟模块、背压/帧尾 RTL 仿真和 PC 距离峰值黄金模型；尚未完成 PL 内 `H=Y/X`、距离 IFFT、目标门和位移链。

## 4. 慢时间频谱
100 Hz抽取、1024/4096窗、窗函数、主频峰值、2.40 Hz和2.05 Hz模式。

## 5. 系统与优化
参数影子寄存器、结果快照、丢样计数、PYNQ界面、断开PC测试；完成字长优化或目标门缓存优化。
